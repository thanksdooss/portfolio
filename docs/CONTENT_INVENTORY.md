포트폴리오에 싣는 모든 항목과 근거 확인 상태를 정리한다.

- ✅ 증빙 확인 — 상장·수료증·원본 산출물로 확인
- ⚠️ 부분 확인 — 사실이지만 표현을 조정해야 함 (조정 내용 기재)
- ❌ 증빙 없음 — 사이트에 싣지 않음

## 7. 싣지 않는 것

- 주소·전화번호·생년월일·계좌·자격번호, 증명사진
- 강의 교재 원본, 시험지, 다른 교육생·팀원 개인 자료
- 크랙 소프트웨어 폴더, 비밀번호가 보이는 캡처, `.env` 파일
- 타인 얼굴이 나온 사진(시상식·활동 단체사진), 발표 영상
- 학교명·로고·캠퍼스 건물명·학번이 보이는 이미지(가림 처리 후에만 사용)
